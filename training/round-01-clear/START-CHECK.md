# B3-1 — 시작 전 지식 체크

이 문서는 B3-1을 시작하기 전에 **Python 구현과 자료구조 학습에 필요한 최소 준비 수준**을 확인하기 위한 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B2-1
- **있으면 좋은 선행 지식:** Python OOP, 자료구조, 시간복잡도(Big-O) 기초

## 자가진단

- [ ] Python 함수와 클래스의 기본 문법을 읽을 수 있다.
- [ ] 객체와 메서드가 무엇인지 대략 설명할 수 있다.
- [ ] list와 key-value 저장 구조의 차이를 이해한다.
- [ ] 자료구조에 따라 조회·삽입 비용이 달라질 수 있다는 점을 알고 있다.
- [ ] O(1), O(n) 같은 시간복잡도 표기를 본 적이 있고 대략적인 의미를 안다.
- [ ] 작은 Python 프로그램을 실행하고 오류 메시지 위치를 찾을 수 있다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- Python 문법만 낯설다면 B2-1의 함수·클래스·파일 구조 부분을 먼저 복습하면 좋습니다.
- 자료구조와 Big-O가 처음이어도 B3-1에서 학습할 수 있으므로 미션 자체를 막지는 않습니다.

> **B2-1 CLEAR는 필수 조건이 아닙니다.** 필요한 Python 기초를 이미 알고 있다면 바로 B3-1로 진입할 수 있습니다.
